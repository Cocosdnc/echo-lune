# ÉCHO-LUNE — simulation de télémétrie laser Terre–Lune

Site pédagogique (physique-chimie, collège) : mesurer la durée aller-retour d'une impulsion laser vers les réflecteurs Apollo, puis calculer la vitesse de la lumière (v = d / t).

Pages : `index.html` (histoire, réflecteurs), `lune.html` (fiche de la Lune, distance), `stations.html`, `console.html` (tir laser, avec le choix de l'onde envoyée : frise du spectre électromagnétique, longueur d'onde de 100 à 1 500 nm, sinusoïde colorée — grise hors du visible ; module `onde.js`).

Mise en ligne : Settings → Pages → Deploy from branch → `main` / root.
Photos : NASA, domaine public, chargées depuis Wikimedia Commons.
